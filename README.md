Developed a Blue Prism robot with supervised OneDrive access for multi‑server deployment and monitoring.
This solution integrates Python executables to overcome Blue Prism’s limitations:
- DOCX logo replacement (adapted from a 2023 handover script)
- PDF → DOCX conversion (custom‑built)
The automation pipeline handles:
- File movement
- Logo removal in DOCX files
- DOCX → PDF conversion
Results: First production run processed 500 documents with a 98% clean PDF rate.
